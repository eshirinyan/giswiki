# ГИС-вики

## Разделы

База знаний помогает перейти от вопроса о городской среде к обоснованной методологии пространственного исследования и проектному решению. Это прототип для магистерской дисциплины по ГИС в архитектуре и градостроительстве.

## Как пользоваться

Начните с заметки в папке «Исследовательские вопросы». Проследите путь к понятию, индикатору, данным и методу. Затем оцените результат, сформулируйте проектное вмешательство и повторите анализ для сценария.

**НАБЛЮДАТЬ → АНАЛИЗИРОВАТЬ → ВМЕШИВАТЬСЯ → ПРОВЕРЯТЬ.** Карта здесь служит аргументом и средством проверки, а не конечной целью.

## Структура и типы

- «Исследовательские вопросы» — `question`: постановка задачи, интерпретация и проверка сценария.
- «Методы» — `method`: логика анализа и ограничения.
- «Индикаторы» — `indicator`: измеримые характеристики.
- «Данные» — `data`: требования к исходным пространственным данным.
- «Понятия» — `concept`: смысл исследуемых свойств среды.
- «Кейсы» — `case`: учебные рамки применения нескольких методов.
- «Материалы» — место для будущих учебных материалов; в прототипе пусто.

## Свойства и связи

Содержательные заметки имеют YAML-свойства `type`, `themes`, `scale`, `methods`, `indicators`, `data`, `outputs`, `related`, `publish` по применимости. Значения на русском языке, кроме технического типа заметки и логического `publish: true`. Темы и масштабы ограничены согласованными словарями.

Связывайте заметки через `внутренние wiki-ссылки` только там, где связь объясняет исследовательский шаг. Цель ссылки должна совпадать с английским именем файла, а русский текст показывается через алиас: `[[methods/network-analysis|Сетевой анализ]]`. Граф знаний отражает цепь: **городская проблема → вопрос → понятие → индикатор → данные → метод → результат → интерпретация → проектное решение → повторный анализ**.

Будущий инструмент **«Построить методологию»** сможет предложить для выбранного вопроса показатели, требования к данным, методы, ожидаемые результаты и способ сравнения сценариев «до → после». Связи и свойства этого прототипа служат основой для такой функции.
