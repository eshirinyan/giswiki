# Нормализованный разностный вегетационный индекс — NDVI

NDVI = (ближний инфракрасный − красный) / (ближний инфракрасный + красный) по отражательной способности поверхности. Индекс помогает выявлять растительность на спутниковом снимке, но сам по себе не показывает доступность парка, тень в часы использования или качество озеленения.

## Исследовательская цепочка

Вопрос [[questions/urban-overheating|о перегреве]] → NDVI и [[indicators/land-surface-temperature|LST]] → снимки одного периода с маской облаков → выявление участков с малой растительностью и высокой температурой → проект озеленения → повторный расчёт по сопоставимым снимкам.

## Ограничения

Небольшие деревья и узкие полосы зелени могут теряться в пикселе. Значения разных сезонов нельзя напрямую считать эффектом проекта.
